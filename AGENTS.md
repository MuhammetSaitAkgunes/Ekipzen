# Repository Workflow

- Keep local work in small, reviewable commits and regularly compare it with the `ikpro` GitHub remote.
- Never merge any branch without the user's explicit approval for that specific merge.
- Never push any commit, branch, or tag without the user's explicit approval for that specific push.
- Treat merge approval and push approval as separate decisions; one does not imply the other.
- Before requesting either approval, report the exact source/target refs, commits, changed files, and verification results.
- Never force-push or rewrite shared history unless the user explicitly approves that exact destructive operation.
